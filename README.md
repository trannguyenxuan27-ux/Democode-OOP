## 📝 Giới thiệu (Overview)
Repository này chứa các đoạn mã thực hành (Democode) được viết bằng **C#**, tập trung vào việc triển khai và minh họa các nguyên lý cốt lõi của **Lập trình Hướng đối tượng (OOP)** và các **Design Patterns** (Mẫu thiết kế phần mềm) phổ biến.

Dự án được xây dựng nhằm mục đích học tập, nghiên cứu và làm tài liệu tham khảo cho môn học Lập trình Hướng đối tượng.

## 🏆 Các khái niệm cốt lõi được triển khai (Core Concepts)
Mã nguồn minh họa chi tiết các kiến thức nền tảng và nâng cao:
*   **4 Tính chất của OOP:** 
    *   Tính Đóng gói (Encapsulation)
    *   Tính Kế thừa (Inheritance)
    *   Tính Đa hình (Polymorphism)
    *   Tính Trừu tượng (Abstraction)
*   **Design Patterns (Mẫu thiết kế):** Áp dụng thành thạo các mẫu như Strategy, Singleton, Factory, và Observer.
*   **Kiến trúc phân lớp (Layered Architecture):** Phân tách rõ ràng giữa Domain, Repository, Service và Presentation.
*   **Xử lý ngoại lệ (Exception Handling):** Tùy chỉnh các lớp ngoại lệ (DomainException, ValidationException, BusinessException) để quản lý lỗi nghiệp vụ.

## 📂 Cấu trúc thư mục (Project Structure)
*   `demo.cs`: Minh họa các khái niệm cơ bản về Class, Object và các phương thức.
*   `demo3.cs`: Triển khai các cấu trúc dữ liệu phức tạp và áp dụng Design Patterns.
*   `ndemo2.cs`: Ứng dụng kiến trúc phân lớp (Service/Repository) và xử lý nghiệp vụ.

## 🛠️ Công nghệ sử dụng (Technologies)
*   **Ngôn ngữ:** C# (.NET 6.0 / .NET 8.0)
*   **Môi trường (IDE):** JetBrains Rider / Visual Studio
*   **Hệ điều hành:** Linux (CachyOS/Arch) & Windows

## 🚀 Hướng dẫn chạy (How to Run)
1. Đảm bảo bạn đã cài đặt [.NET SDK](https://dotnet.microsoft.com/download).
2. Clone repository này về máy:
   \`\`\`bash
   git clone https://github.com/trannguyenxuan27-ux/Democode-OOP.git
   \`\`\`
3. Di chuyển vào thư mục dự án và chạy file mong muốn:
   \`\`\`bash
   dotnet run --project demo.cs
   \`\`\`
